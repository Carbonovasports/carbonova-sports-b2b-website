# Carbonova Sports repository rules

- Production domain: https://www.carbonovasports.com/
- Brand: Carbonova Sports
- Legal manufacturer: Xiamen Carbon Rock Material Technology Co., Ltd.
- Keep existing public URLs stable unless an explicit migration/redirect plan is approved.
- Never invent certifications, certificate IDs, customers, sales volumes, reviews, ratings, prices, SKUs, GTINs, inventory status, or unverified product specifications.
- Do not change certification data or the WhatsApp number without explicit approval.
- Preserve the current static HTML/CSS/JS architecture and Carbonova visual design unless redesign is explicitly requested.
- Technical SEO changes should use a branch + pull request workflow and must not overwrite recent Accio Work content changes.
- Product structured data may use only facts already present on the page or otherwise explicitly verified.
- For Product schema, omit Offers/price/reviews/ratings/availability unless verified data exists.
- Padel and Pickleball are both primary categories; general site metadata should not incorrectly describe Carbonova as pickleball-only.
